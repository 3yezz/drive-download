# EDdrive

**Français** | [English](#english)

---

## Français

EDdrive est une application de stockage et de gestion de fichiers en ligne, disponible sur Windows, Linux, macOS et Android.

### Fonctionnalités

- Navigation et gestion des fichiers cloud
- Prévisualisation de documents et images
- Rendu Markdown intégré
- Téléversement et téléchargement de fichiers
- Interface réactive adaptée bureau et mobile

### Plateformes

| Plateforme | Format |
|------------|--------|
| Windows | `.exe` (installeur NSIS) |
| Linux | `.tar.gz` |
| macOS | `.dmg` |
| Android | `.apk` |

### Installation

Télécharge la dernière version depuis les [releases GitHub](https://github.com/3yezz/drive/releases).

### Stack technique

- **Interface** : React 18
- **Markdown** : marked.js
- **Bureau** : Electron
- **Mobile** : Android natif (WebView)
- **Build** : electron-builder, Gradle

---

## English

EDdrive is a cloud file storage and management application available on Windows, Linux, macOS and Android.

### Features

- Browse and manage cloud files
- Document and image preview
- Built-in Markdown rendering
- File upload and download
- Responsive interface for desktop and mobile

### Platforms

| Platform | Format |
|----------|--------|
| Windows | `.exe` (NSIS installer) |
| Linux | `.tar.gz` |
| macOS | `.dmg` |
| Android | `.apk` |

### Installation

Download the latest version from the [GitHub releases](https://github.com/3yezz/drive/releases).

### Tech stack

- **UI** : React 18
- **Markdown** : marked.js
- **Desktop** : Electron
- **Mobile** : Android native (WebView)
- **Build** : electron-builder, Gradle
